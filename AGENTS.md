# AGENTS.md

## Project

Flutter attendance-checker app (Android + Web) backed by Firebase. Firebase project: `attendance-checker-9f22b`. Not iOS/macOS/Windows/Linux.

## Commands

- `flutter pub get` — install dependencies
- `flutter analyze` — run static analysis (uses `package:flutter_lints` + `avoid-dynamic` rule)
- `flutter build apk --release` — build Android APK
- `flutter build appbundle --release` — build Android AAB
- `flutter test` — run tests (only default counter test exists; won't pass against this app)

No single-file test runner. No lint/typecheck CI gate — the only CI is `.github/workflows/release.yml` (build on tag push `v*`).

## Architecture

Entry: `lib/main.dart` → `AuthGate` → `LoginScreen` (unauthenticated) or `HomeScreen` (authenticated, role-gated).

State management: **Provider**. Two main providers registered in `main.dart`:
- `FolderProvider` — folders, students, offline sync queue
- `AttendanceEventProvider` — attendance events + records subcollections

`AttendanceProvider` (in `lib/providers/attendance_provider.dart`) is a legacy/parallel provider storing records in `users/{uid}/records` — separate from event records.

## Firestore Structure

- `users/{uid}` — user profile (role: "admin" or "officer")
- `users/{uid}/records/{recordId}` — legacy attendance records (AttendanceProvider)
- `folders/{folderId}` — class sections (name, ownerId, sharedWith, files)
- `students/{studentId}` — students with `folderId` field (migrated from embedded in folders)
- `attendance_events/{eventId}` — attendance events
- `attendance_events/{eventId}/records/{recordId}` — event attendance records
- `app_config/latest` — forced update config (read-only for clients)

## Offline-First Pattern

All three providers queue pending actions in `SharedPreferences` when offline, then sync when connectivity returns. Action types vary per provider — see `_executeAction` / `_executeFolderAction` methods.

## Key Gotchas

- `firebase_options.dart` is **generated by FlutterFire CLI** — do not edit manually. Only Android and Web are configured.
- `package.json` + `migrate*.js` are for Firebase migration scripts only (run via Node with `firebase-admin`). Not part of the Flutter app.
- `.env` and `assets/env.txt` are gitignored — do not commit secrets.
- Brand color: `#457507` (Material 3 seed). Portrait-only orientation enforced in `main.dart`.
- Students use `AttendanceType` enum: `timeIn` | `timeOut`.
- Student IDs are millisecond timestamps or UUIDs (varies by creation path).
- The `home_screen.dart` syncs both providers on app resume via `WidgetsBindingObserver`.

## Conventions

- No comments in code unless asked.
- Models use `toMap()`/`fromMap()` for Firestore, `toJson()`/`fromJson()` for local cache, `toJsonString()`/`fromJsonString()` for string serialization.
- Screens follow `{feature}_screen.dart` naming.
- `flutter_launcher_icons` configured for Android only (`assets/icon.png`).
